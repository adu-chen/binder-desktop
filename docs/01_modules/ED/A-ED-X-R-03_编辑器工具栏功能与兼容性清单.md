# 编辑器工具栏功能与兼容性清单

## §1 目的与读法

工具栏保持两条常驻行：第一行是**编辑器级工具**，第二行是**文档级工具**。图片和表格不占用第三行，
而是在选中对象附近显示临时工具组。窄窗口时各行横向滚动，工具组内部以菜单展开，避免压缩正文区。
每个已打开的菜单在鼠标指针或键盘焦点进入菜单外部时自动关闭；菜单内部的输入、色板和格式操作不触发关闭。

本文把“是否能点击”与“能否安全保存、重开或转换”分开记录：

| 状态 | 含义 |
|---|---|
| 已实现 | 当前 UI 已有入口，命令已接入编辑器。 |
| 已验证 | BDocx capability manifest 标记为 `verified`，或现有转换测试有明确往返证据。 |
| 待验证 | manifest 为 `required_pending`；可编辑，但 DOCX 保存、重开或导出仍需专项回归。 |
| 尽力而为 | manifest 为 `best_effort`；允许使用，但字体替代或格式归一化可能改变结果。 |
| 不支持 | manifest 为 `unsupported`；当前 UI 若仍暴露，只能视为会话内编辑，不应承诺保存/重开/导出后保留。 |
| 不提供 | 当前产品没有安全入口，或明确在范围外。 |

`BDocx` 指当前 DOCX 编辑会话（`editFormat=html`）；`HTML` 指 `.html` 文件编辑会话；Markdown 可在富文本视图与源码视图间切换。

## §2 状态与格式适配总览

| 编辑状态 | 第一行 | 第二行 | 核心边界 |
|---|---|---|---|
| 纯文本（`.txt` 等） | 保存、撤销重做、查找替换、跳转行号、导出 DOCX、缩放 | 段落组：引用、代码块、分隔线 | 仅展示可在纯段落文档生效且内容可保存的段落级结构工具；文字级样式（加粗/颜色/字体/字号等）不展示（txt 保存为纯文本，不持久化）。 |
| Markdown 富文本视图 | 第一行完整；可切源码；查找替换作用于 ProseMirror 文档；定位按内容块 | 样式、文字、段落、列表、插入；仅显示可由 Markdown 子集表达的文字能力 | 保存前必须通过 Markdown Codec；无法承载的源码保留/降级，不静默改写。 |
| Markdown 源码视图 | 第一行完整；查找替换与跳转按真实行号；可切回富文本 | 隐藏，显示“请使用 Markdown 语法” | 源码是此视图的直接编辑面，格式按钮不应伪装为可用。 |
| BDocx（`.docx/.doc`） | 第一行完整；分页出现时显示页码导航；可导出 PDF/Markdown | 样式、文字、段落、列表、插入、页面视图，以及对象就近工具 | 是否安全往返取决于 §5 等级；页面/缩放是呈现偏好，不等于写入 Word 页面设置。 |
| HTML 文件 | 第一行完整；当前不显示导出入口 | 富文本菜单（不含 BDocx 页面视图） | 保存为当前支持的 HTML 表达；外部复杂 CSS/HTML 不在 DOCX 兼容承诺内。 |
| 预览模式（PRV 只读） | 第一行按预览类型自适应：创建草稿进行编辑（仅原生 docx）、导出（docx→PDF/MD；xlsx/pptx→PDF）、缩放（image/table）、打印（pdf/table） | 不适用（第二行隐藏） | 预览纯只读（BR-PRV-DATA-001）；仅查看/输出类工具，无编辑命令；不提供关闭工具（TabStrip 标签 × 承担）；pdf 缩放由 iframe 内 WKWebView 原生查看器控制，工具栏不提供。 |

## §3 第一行：编辑器级工具

| 分组/工具 | 当前逻辑 | 适用状态 | 实现情况与限制 |
|---|---|---|---|
| 保存 | 触发当前活动编辑器的受控保存处理器，并反馈保存中/成功/失败 | 全部 | 已实现；经 ED→WS 保存路径，不直接写磁盘。导出前必先保存。 |
| 撤销 / 重做 | TipTap `undo` / `redo`；不可执行时禁用 | 全部 | 已实现；只影响当前编辑会话。 |
| 查找 / 替换 | 查找下一处、替换当前、替换全部；富文本经 ProseMirror transaction，源码视图直接修改源码文本 | 全部 | 已实现；查找按文本匹配，不提供正则、大小写、全词或跨文档搜索。 |
| 定位 | 纯文本与 Markdown 源码按行号；富文本按顶层内容块（界面称“段落”） | 全部 | 已实现；富文本不承诺按视觉折行定位。 |
| 页码导航 | 上一页、下一页、下拉选择页；仅在分页缝存在时出现 | 有分页呈现时 | 已实现；是滚动定位，不写入 LogicalState，也不生成页码字段。 |
| Markdown 源码/富文本 | 在 Markdown 富文本与源码视图间切换 | Markdown | 已实现；解析失败或不支持语法时保留源码保护路径。 |
| 导出 | `.txt/.md/.markdown` → DOCX；`.doc/.docx` → PDF、Markdown | 对应路径 | 已实现；调用 `prv.export`，仅展示已支持组合；转换失败返回错误，不静默降级。 |
| 打印 | 不在编辑器提供 | — | 不提供；仅只读预览成功后的 PRV 流程可打印，避免打印未保存内容或编辑壳。 |
| 缩放 | 50%–200%，10% 步进，默认 100% | 全部 | 已实现；CSS 纯呈现缩放，不改文档内容、不产生脏态。 |

## §4 第二行：文档级工具与分组

### 4.1 样式与文字

| 分组 | 工具 | Markdown 富文本 | BDocx / HTML | 当前兼容性说明 |
|---|---|---:|---:|---|
| 样式 | 正文、标题 1–6 | 已实现 | 已实现 | BDocx 标题为已验证；其他结构仍随转换子集而定。 |
| 文字 | 加粗、斜体、删除线 | 已实现 | 已实现 | 加粗 verified；斜体为待验证；删除线在 BDocx 为不支持风险。 |
| 文字 | 行内代码 | 已实现 | 不显示 | BDocx `code` 不支持，因此不在富文本菜单暴露。 |
| 文字 | 下划线 | 不显示 | 已实现 | BDocx 为待验证。 |
| 文字 | 文字颜色 | 不显示 | 已实现 | BDocx text color verified；颜色入口归入“文字”，不再单独建“颜色”分组。 |
| 文字 | 文字背景（取色器） | 不显示 | 已实现 | **BDocx 不支持**：会话内可见不等于保存/重开后保留；UI 为与文字颜色同款取色器，去除颜色即去除背景（ED-HIGHLIGHT-BACKGROUND-01 收敛）。 |
| 文字 | 上标 / 下标 | 不显示 | 已实现 | **BDocx 不支持**：会话内可见不等于保存/重开后保留。 |
| 文字 | 字号 | 不显示 | 已实现 | BDocx 为尽力而为；只支持工具栏给出的 pt 值，字体替代或归一化可能变化。 |
| 文字 | 字体 | 不显示 | 已实现 | **本地字体库同步**（ED-FONT-LOCAL-LIBRARY-01）：常用子集置顶（仅可用展示）+ macOS 本地已装字体追加（CoreText 枚举）；不可用字体不渲染（document.fonts.check）；多词字体名写入加引号。BDocx 往返仍为尽力而为；系统/模板缺字或替代字体会改变外观。 |
| 文字 | 清除格式 | 已实现 | 已实现 | 清除 mark，保留段落结构；应避免将其理解为恢复原始 DOCX 样式。 |

### 4.2 段落、列表、插入与页面视图

| 分组 | 工具 | Markdown 富文本 | BDocx / HTML | 当前兼容性说明 |
|---|---|---:|---:|---|
| 段落 | 左/中/右/两端对齐 | 不显示 | 已实现 | BDocx `paragraph_align` 待验证；独立图片对齐另见 §5。 |
| 段落 | 引用、代码块、分隔线 | 已实现 | 已实现 | Markdown 为已定义子集；BDocx 代码块与分隔线没有 verified 往返承诺。 |
| 列表 | 无序 / 有序列表 | 已实现 | 已实现 | BDocx 基础列表待验证。 |
| 列表 | 任务列表 | 已实现 | 不显示 | 仅 Markdown GFM 子集。 |
| 列表 | 提高 / 降低层级 | 当前 listItem 时可用 | 当前 listItem 时可用 | 已实现；非列表项禁用，不把普通段落伪装成可缩进。 |
| 插入 | 链接 | 已实现 | HTML 文件可用；BDocx 不显示 | BDocx link 不支持；BDocx 不暴露远程 URL 入口。 |
| 插入 | 图片 | URL 提示插入 | HTML 文件可提示插入；BDocx 按钮禁用并提示本地 PNG/JPEG 拖入 | BDocx 图片受控拖入及图片资源往返已验证；不提供不受控本地路径/Data URL 替换。 |
| 插入 | 3×3 表格 | 已实现 | 已实现 | BDocx basic_table 待验证；复杂布局不在承诺内。 |
| 页面视图 | 纸张 A4/A3/A5/Letter、横/竖向 | 不显示 | 已实现 | 仅 BDocx 分页视图偏好和几何；manifest 中 page size 为模板继承，不能理解为已写入 DOCX 页设置。 |

## §5 选中对象就近工具

| 工具 | 出现条件 | 当前状态 | 兼容性/保护边界 |

## §6 需要产品决策的风险清单

| 优先级 | 风险/不一致 | 当前表现 | 用户影响 | 建议后续决策 |
|---|---|---|---|---|
| P0 | BDocx 删除线、高亮、上下标被 UI 暴露，但 manifest 均为 `unsupported` | 可在编辑会话中点击 | 保存、重开、导出后可能丢失或变形 | 在完成 DOCX 往返验证前，隐藏 BDocx 入口或明确标出不保证保存。 |
| P0 | BDocx 表格合并/拆分被 UI 暴露，但 `merged_cells` 为 `unsupported` | 选区满足时可点击 | DOCX 结构可能无法往返 | 在实现 DOCX 合并单元格支持前，禁用/隐藏这两个入口。 |
| P1 | BDocx 段落对齐、斜体、下划线、列表和基础表格为 `required_pending` | 已可编辑 | 当前无完整验证证据 | 建立“编辑→保存→重开→导出”样例矩阵后再提升为兼容承诺。 |
| P1 | 字号、字体为 `best_effort` | 已可编辑 | 字体缺失、替代或规范化会改变排版 | 在菜单/保存提示中声明尽力而为，并提供样例验收。 |
| P1 | 页面视图与 Word 页面设置容易混淆 | 可选择纸张、横竖向 | 用户可能误以为修改 DOCX 页尺寸 | 文案保持“页面视图”；若需写入页面设置，应新增 DOC 转换能力和验证。 |
| P2 | HTML/Markdown 与 DOCX 导出是转换，不是无损复制 | 已提供受支持格式导出 | 高级结构或未声明样式可能降级 | 在导出前提示目标格式约束，并由 PRV/DOC 返回明确错误或风险信息。 |
| P2 | 桌面真机交互尚需持续验收 | 自动化覆盖命令与状态 | 菜单定位、横向滚动、原生颜色选择器与选区体验可能因 WebView 有差异 | 对 macOS WKWebView 完成手工验收后更新本文状态。 |

## §7 已知不提供的能力

- 编辑态打印、页眉页脚编辑、自动页码、脚注、页边距写入。
- BDocx 图片本地替换、远程 URL 插图、浮动/文字环绕/裁剪/旋转和绝对定位。
- 表格的表头列、行高、数值列宽、均分列、复杂边框和复杂 Word 表格样式。
- Markdown 无法无损表达的富文本样式：颜色、高亮、下划线、上标、下标、字体和字号等。
- 查找替换的正则、大小写、全词、跨文档及格式查找。

## §8 当前验证与维护动作

- 已有自动化：`EditorControls.test.tsx` 覆盖两行模式、保存、查找替换、定位、导出、图片/表格临近控件、
  高亮自定义与清除、删除线、颜色归组，以及菜单的外部指针/焦点自动关闭与组内交互保持；
  `PrvToolbar.test.tsx` 覆盖预览模式 5 类型自适应矩阵（创建草稿/导出/缩放/打印显隐与禁用态）。
- 最近相关验证：组件测试 11/11（EditorControls）+ 11/11（PrvToolbar）；相关前端回归通过；TypeScript、
  生产构建、治理审计与差异检查通过。
- 已接受环境风险：完整 Rust 回归的 LibreOffice PDF 端到端测试在当前环境出现 worker `signal=6`
  （262/263）；这不是工具栏代码失败，但会阻塞 DOCX→PDF 的端到端环境验证。
- 下一次工具栏改动应先更新本文矩阵，再决定入口显示、禁用、警告或转换能力的实际实现。
