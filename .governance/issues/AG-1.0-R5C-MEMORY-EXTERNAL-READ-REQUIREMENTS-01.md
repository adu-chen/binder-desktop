# Issue Trace — AG-1.0-R5C-MEMORY-EXTERNAL-READ-REQUIREMENTS-01：受控外部文件读取与用户管理的项目记忆

文档状态：A
任务类型：DOC_ONLY
治理阶段：REQUIREMENT
创建时间：2026-08-14

## 1. 用户可见问题

用户可拖入外部文件，但此前 1.0 只把它作为 name/path/size 元数据引用，无法在不扩大本地读取权限的前提下对内容进行分析。与此同时，现有文档对长期项目记忆同时出现了“自动写入/自动供给”的旧描述与 `agent-edit-1.0`“不自动写入或注入”的新基线，用户无法判断哪些内容会被保留、何时会被 Agent 使用。

## 2. 已核实的设计漂移

- REF 现有 P0 只允许外部文件形成元数据引用；其“外部文件仍只形成元数据”的表述必须让位给 R5-C 的受控 P1 内容引用路径。
- AST 的通用流程仍描述 AG 生成记忆写入提议、按自动策略落库和相关性注入；这与 Agent 1.0 Profile 已确认的“无自动写入、无自动注入”冲突。
- AG/CORE/SYS 已明确会话、编辑和任务事实可以本地恢复，但不应把这条事实链误推为外部文件内容或长期记忆可以自动持久化/注入。

本轮只修订 L1 需求边界；不修改 AST/REF/AG/SYS 的 L2、状态机、接口、代码、Prompt 或测试。

## 3. 本轮人类确认

1. 外部文件实际读取是 P1：只有用户显式拖入/选择的文件才可读；只有系统已有可用只读解析能力的格式才形成内容引用，不支持或不可读的文件保留元数据引用并如实说明。
2. 外部文件内容只作为当前用户任务的一次性 data-only 上下文：不扫描外部目录、不自动再次读取、不授予写入/执行权限、不默认写入会话历史或项目记忆。
3. 长期项目记忆是 P1、本地 workspace 隔离的用户资产：用户可创建、查看、编辑、删除、关闭；不会跨 workspace 共享或上云。
4. `agent-edit-1.0` 不自动写入、也不生成记忆写入提议；不按相关性自动检索或注入。只有用户明确选择的记忆条目，才能由 REF 作为 data-only 引用进入当前 AgentTurn。
5. 外部文件内容不会自动转存为项目记忆；未来如开放 Agent 提议/自动写入或注入，必须独立确认、设计和验证。

## 4. 需求边界

- 内容引用的“可读”只表示存在经过用户显式触发、受支持的只读读取路径；它不表示 Agent 能浏览、搜索、遍历、导入或编辑外部文件系统。
- 外部文件内容与记忆正文均为不可信 data-only。它们不能改变系统约束、当前目标、工具授权、编辑目标或确认点。
- 外部内容的任务结束后默认不再向后续回合开放；重启、恢复、跨会话或跨 workspace 不得伪装为仍可读取。
- 记忆是用户管理的本地项目资产，不是会话事实、编辑历史、知识库或外部文件的自动副本。

## 5. 直接消费者

- CORE：新增外部内容与项目记忆的产品级 P1、用户控制和保留边界。
- AG：只消费当前任务已授权的外部内容/用户选择记忆，保持最小上下文与无写入权限。
- REF：将外部文件由 P0 元数据引用扩展为 P1 受控内容引用，并承载显式记忆引用。
- AST：将 Agent 1.0 的记忆写入和注入收束为用户手工管理/显式选择，旧自动流程移至未来 Profile。
- SYS：声明外部内容与记忆在 workspace、AgentSession、AgentTurn 中的隔离/恢复边界。

## 6. 验收计划

- 外部文件：拖入可读格式后，用户能看见来源和“内容只供当前任务”的范围；分析可引用实际内容；没有写 Proposal 权限。拖入不支持格式时，只保留元数据并明确未读内容。
- 隔离与保留：任务后、重启后、另一个会话或 workspace 中，外部文件内容不会被自动再用或伪称仍可访问。
- 项目记忆：用户可在本 workspace 创建、查看、编辑、删除、关闭条目；仅用户选中的条目可进入当前回合，来源可追溯且为 data-only。
- 禁止路径：普通 Agent 发送、外部文件拖入和会话恢复均不会自动创建、提议写入、检索或注入长期项目记忆。

## 7. 待设计项

- 外部文件格式清单/可用解析器、大小与上下文预算、内容快照/暂存/清除、来源显示、传输提示、错误、脱敏 Trace 与可访问性。
- 记忆条目字段、手工管理 UI、关闭语义、删除传播、来源模型、显式选择令牌、workspace 存储、事件、IPC、数据库 schema 与状态机。
- 未来 Profile 的 Agent 记忆提议/自动写入/自动注入，及其用户确认、撤销、评测和隐私策略。

## 8. 风险与迁移债务

- 如果把“用户拖入文件”实现为目录可读或自动重复读取，会将一次性资料交给不受控制的上下文扫描。
- 如果将外部文件内容或会话事实自动沉淀为项目记忆，用户无法辨别持久化范围和后续模型输入。
- 如果让 AST 旧自动写入/注入规则在 Agent 1.0 生效，会绕过已确认的用户选择边界。
- 不得只用 Prompt 忽略外部内容或静默清理记忆来伪造满足；后续必须有真实的读取、隔离、用户控制和验证链。

- 自动目录扫描、外部文件导入/编辑、自动或批量网络读取、知识库自动检索、会话删除/归档细节。
- Agent 记忆提议、自动写入、自动注入、云同步、跨 workspace 共享和任何跨重启的外部内容自动恢复。
